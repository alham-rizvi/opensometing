# Open Stacker

A community-curated directory of the best open-source alternatives to popular software and developer tools.

## Setup

### Using Docker

```bash
docker build -t open-stacker .
docker run -p 5173:5173 open-stacker
```

### Using Podman

```bash
podman build -t open-stacker .
podman run -p 5173:5173 open-stacker
```

## Local Development

```bash
bun install
bun run dev
```

## Technologies

- React + TypeScript
- Vite
- Tailwind CSS
- Supabase
